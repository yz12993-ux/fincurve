Which curve does your financial data actually follow?

fincurve profiles the data, picks the right noise model and validation scheme, fits 32 candidate forms — from Nelson–Siegel and SVI to hazard curves and power laws — and ranks them by held-out likelihood. It also knows when not to fit a curve.

// 01 — pipeline

Six steps from raw data to a defensible choice

Every decision is made from the data and written into the report, so you can audit why a form won.

  1. 01

    Profile

    Target type, shape, noise versus level, time ordering, and finance context read from the column name.

  2. 02

    Likelihood

    Gaussian, log-normal, binomial or Poisson. When unclear, additive and multiplicative noise compete.

  3. 03

    Validation

    Shuffled K-fold, rolling-origin for time series, grouped folds, or leave-one-out for tiny samples.

  4. 04

    Fit

    32 forms × multi-start bounded least squares. Linear coefficients are solved on grids for stable starts.

  5. 05

    Rank

    Held-out NLL per row. A tie needs both 2 paired SE and a 0.1-nat gap; the simplest tie wins.

  6. 06

    Guardrails

    Random walks, half-peaks, extrapolation disagreement, heavy tails, leakage, volatility clustering.

// 04 — method

How a winner is chosen

Not R². Held-out likelihood, a paired standard error, and a practical-equivalence gap.

score

Held-out likelihood, per row

ℓ̄m = (1/n) Σi −log pm(yi | xi, θ̂−fold(i))

Parameters are refit without the fold that contains row i. Gaussian, log-normal, binomial and Poisson models share one scale, so additive and multiplicative noise compete directly.

tie rule

Two conditions for a tie

Δm ≤ 2·SEpaired  ∧  Δm ≤ 0.1 nats  ⇒  argmintied k

The paired standard error uses per-row differences against the best model. The 0.1-nat gap (≈10% RMSE under Gaussian errors) stops small samples from declaring everything equal. Among tied models, the one with the fewest parameters is recommended.

nested cv

Shape search inside every fold

for k in folds: shapesk = search(traink); score(testk | shapesk)

In multi-feature mode the greedy shape and interaction search is repeated on each training fold, so the reported score is not flattered by the search. Fold-to-fold effect-curve correlation tells whether a shape is real.

guardrails

What it warns about

  • random-walk paths — curve withheld, returns analysed instead
  • peak shapes fitted to monotone data
  • tied models that disagree once extrapolated
  • heavy-tailed residuals and outliers
  • row-number / ID leakage and collinear features
  • volatility clustering in return samples
// 05 — library

32 candidate forms

Each form carries its bounds, domain rules and grid-based starting values. GLM versions with logit or log links are added automatically for binary, proportion and count targets.

// 06 — quick start

Try it in a minute

Dependencies are numpy, scipy, pandas and matplotlib — nothing else.

shell 
pip install git+https://github.com/yz12993-ux/fincurve
python 
from fincurve import analyze

report = analyze(df["tenor"], df["yield"])                # one x → curve
report = analyze(df[["leverage", "rating"]], df["spread"])  # many features
report = analyze(df["daily_return"])                       # sample → distribution

report.summary()        # plain-language report
report.plot("out.png")  # data, top curves, residuals, ranking
report.ranking          # ΔCV-NLL, SE, ties, AIC for every form
reproduce this page 
git clone https://github.com/yz12993-ux/fincurve && cd fincurve
python tests/run_tests.py          # 16 regression tests with known ground truth
python site/build_site_data.py     # regenerates every number on this page

Plain-language reports are currently written in Chinese; the structured results (report.ranking, report.recommended, report.warnings) can be used from any language.
