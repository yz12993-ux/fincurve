# fincurve：金融数据的函数形式刻画器

[English](README.md) · [在线演示](https://yz12993-ux.github.io/fincurve/)

给它一组数据，它会自动判断数据类型，选择合适的误差模型和验证方式，把 32 种候选函数（包括收益率曲线、波动率微笑、债券定价、违约曲线、期权等金融专用形式）全部拟合一遍，按**留出数据上的似然**排名，最后给出推荐结果、中文报告和图。

依赖只有 `numpy`、`scipy`、`pandas`、`matplotlib`。

## 三种用法

```python
from fincurve import analyze

# 1) 一个 x：找最合适的曲线 y = f(x)
report = analyze(df["期限（年）"], df["收益率"])

# 2) 多个特征：每个特征自动选形状，并检测交互项
report = analyze(df[["杠杆率", "剩余期限", "评级", "行业"]], df["信用利差"])

# 3) 只有一列样本：找最合适的分布（重点看尾部）
report = analyze(df["日收益率"])

report.summary()          # 中文报告
report.plot("out.png")    # 数据 + 前几名曲线 + 残差 + 排名
report.ranking            # 完整排名表（DataFrame）
report.recommended        # 推荐模型对象
report.predict(new_x)     # 用推荐模型预测
report.warnings           # 需要注意的问题
```

`from fincurve import list_candidates; list_candidates()` 会列出全部候选函数，以及它们的公式、参数和金融含义。

## 它自动做了哪些判断

| 判断 | 依据 | 结果 |
|---|---|---|
| y 是什么类型 | 取值范围、是否整数、是否只有 0/1 | 连续 / 正值 / 比例 / 0-1 / 计数 |
| 用什么误差模型 | y 的类型；正值时看噪声是否随水平放大；计数时看离散度 | 加性（正态）、乘性（对数正态）、二项、Poisson；拿不准时让加性和乘性都参与比较 |
| 是不是时间序列 | x 是日期；x 的名字像时间；x 等间距且 y 像随机游走 | 是：按时间滚动验证，不打乱顺序 |
| 是不是价格路径 | 相邻值高度相关、差分近似独立、多尺度方差比约为 1、去趋势后残差仍自相关 | 提醒“曲线形状没有意义”，并自动附上收益率的分布分析 |
| 用哪种交叉验证 | 分组 / 时间顺序 / 样本量 | 按组 K 折 / 滚动 / 留一法（n < 20）/ 随机 5 折 |
| x 的金融语境 | x 的名字：期限、行权价、收益率、评分、标的价格 | 提示对应的专用形式（如 Nelson–Siegel、SVI）排在第几名 |
| 哪些特征不能用 | 常数列、行号、ID、高基数类别 | 自动剔除，防止泄漏 |

## 候选函数库（32 种）

| 类别 | 函数 |
|---|---|
| 基准、多项式 | 常数、线性、二次、三次 |
| 指数 | 指数、指数趋近（均值回复）、双指数（两因子） |
| 幂律 | 幂律、幂律+偏移、截断幂律 |
| 边际递减 | 对数、平移对数、平方根、反比、有理函数 |
| 饱和、S 形 | Michaelis–Menten、Hill、逻辑斯蒂、Gompertz |
| 峰形、分段、周期 | 高斯峰、洛伦兹峰、单拐点折线、平滑曲棍球杆、周期+趋势 |
| 期限结构 | Nelson–Siegel、Svensson、Heston 平值波动率期限结构 |
| 波动率 | SVI 微笑 |
| 固定收益 | 现金流贴现价格（价格–收益率凸性） |
| 信用 | 常数违约强度累计违约率、Weibull 违约曲线 |
| 期权 | Black–Scholes 期权价格–标的形状 |

当 y 是比例或计数时，还会加入带连接函数的版本（如 `expit(线性)`、`exp(二次)`）。

## 怎么读排名

- **ΔCV-NLL**：与最优模型相比，每个观测的留出负对数似然之差，越小越好。它把加性、乘性、二项、Poisson 放在同一把尺子上比较；在正态误差下，0.1 大约对应 RMSE 差 10%。
- **并列（=）**：差距在 2 个配对标准误以内，**并且**小于 0.1。第二个条件是必须的：小样本时标准误很大，只用第一个条件会让几乎所有模型都“并列”。
- **推荐（★）**：并列模型中参数最少的那个。
- **非参数参照**：曲线模式用局部线性平滑，多特征模式用 K 近邻。如果参照明显更好，说明候选库里可能缺少真实形状。

## 多特征模式怎么工作

1. 每个数值特征先按线性处理，类别特征用 one-hot（稀有类别并入“其他”）。
2. 逐个特征尝试 11 种形状（二次、三次、对数、平方根、反比、幂律、指数、S 形、单峰、折线），AIC 至少下降 4 才更换，重复两轮。
3. 在最重要的 4 个数值特征之间尝试乘积交互项，AIC 至少下降 10 才加入。
4. **交叉验证在每一折里重新做第 2、3 步**，分数不会因为“在全样本上挑形状”而偏乐观；同时比较各折的效应曲线，检查形状是否稳定。
5. 报告每个特征的走势（如“上升趋缓”“S 形上升”）、重要性（贡献方差占比）和各折一致性。

## 局限

- 非线性拟合用多起点最小二乘，仍可能停在局部最优；参数很多的形式（Svensson、SVI）在点很少时尤其敏感。
- 样本很少（十几个点）时，排名本身就不稳定，报告会提醒，但不能替代更多数据。
- 分数衡量的是**数据范围内**的预测能力。并列模型外推时可能差异很大，报告会估算这种分歧，但结论仍然是：不要外推。
- 时间序列只做了滚动验证，没有对自相关误差建模；分布模式假设样本独立，检测到波动聚集时只提醒，不拟合 GARCH。
- 多特征模式是加性结构加少量乘积交互，复杂的高阶交互需要树模型等方法。
- 耗时参考（本机）：曲线模式 100 个点约 5 秒、3000 个点约 17 秒；多特征模式 1500 行约 6 秒、1 万行 5 个特征约 55 秒（`nested=False` 可以大幅加快，代价是分数略偏乐观）。

## 目录

```
fincurve/
  core.py          入口 analyze：数据画像、自动决策、提醒
  library.py       32 种候选函数（公式、边界、定义域、起始值）
  families.py      误差模型：正态、对数正态、二项、Poisson
  profile.py       数据画像：形状、噪声、随机游走检验、语境识别
  univariate.py    曲线模式：拟合、交叉验证、外推分歧
  additive.py      多特征模式：形状搜索、交互项、嵌套交叉验证
  distribution.py  分布模式：12 种分布、尾部误差、波动聚集检验
  scoring.py       交叉验证切分、配对标准误、推荐规则
  report.py        报告对象与中文摘要
  plotting.py      三种模式的图
examples/
  scenarios.py     11 组带已知真实形式的模拟金融数据
  demo.py          批量运行，输出到 examples/output/
site/build_site_data.py  从真实运行结果生成网页数据
docs/              展示网页（GitHub Pages）
tests/run_tests.py 16 个回归测试
```
